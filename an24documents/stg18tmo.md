# СТГ-18ТМО — Стартер-генератор основных двигателей

## Назначение

СТГ-18ТМО — стартер-генератор постоянного тока, установленный на каждом двигателе АИ-24. Работает в двух режимах:

1. **Стартерный** — раскрутка ротора двигателя АИ-24
2. **Генераторный** — питание бортсети постоянного тока (28.5В)

## Стартерный режим

### Обороты

Частота вращения вала стартера определяется формулой:

```
n = (U - Iя·(Rя + Rд)) / (c · Фв)
```

Где:
- `U` — напряжение на шине запуска
- `Iя` — ток в якорной обмотке
- `Rя` — сопротивление якорной обмотки
- `Rд` — дополнительное сопротивление (в ПСГ-1А)
- `c` — конструктивная постоянная
- `Фв` — магнитный поток возбуждения (пропорционален току возбуждения)

### Регулирование оборотов

Обороты стартера регулируются двумя способами:

1. **Напряжение на якоре** — изменяется ступенчато через:
   - Дополнительное сопротивление Rд (включено = малые обороты, выключено = полное напряжение)
   - ПРК-8А (при питании от ГС-24А) — ступенчатое увеличение напряжения

2. **Ток возбуждения** — изменяется регулятором **РУТ-600Д2**:
   - При увеличении тока возбуждения → Фв ↑ → момент ↑ → при ограничении Iя → обороты растут
   - При уменьшении тока возбуждения → Фв ↓ → момент ↓ → обороты падают

## Генераторный режим

При работе двигателя СТГ-18ТМО переключается в генераторный режим, обеспечивая питание бортсети 28.5В.

## Отсечка стартера

Стартер автоматически отключается:
1. **По сигналу пневмоэлектрического выключателя ВС-1А** — при достижении ротором двигателя 33-48% оборотов
2. **По времени** — если обороты не достигнуты за 70 секунд

## Контроль

- Амперметр «Ток запуска» — ток в якорной обмотке (шкала до 1000А, не должен превышать 1000А более 3-4 сек)
- Вольтметр «Напряжение запуска» — 0-75В, цена деления 2В
