# 12-САМ-28 — Бортовые аккумуляторные батареи

## Назначение

Батареи 12-САМ-28 на самолёте предназначены для:
1. Питания жизненно важных потребителей при отказе обоих генераторов СТГ-18ТМО
2. Запуска газотурбинной установки при отсутствии аэродромного источника
3. Питания бортовой сети при запуске двигателей от ВСУ

## Основные характеристики

| Параметр | Значение |
|----------|----------|
| Тип | Свинцово-кислотный |
| Количество элементов | 12 |
| Номинальное напряжение (заряженная) | 24-25 В |
| Напряжение при нагрузке 12А | ≥24 В |
| Ёмкость (5-часовой разряд) | 28 А·ч |
| Ток разряда (номинальный) | 5.6 А |
| Минимальное напряжение разряда | 21 В |
| Плотность электролита (заряженная) | 1.285 г/см³ |

### Шифр
- **12** — количество последовательно соединённых элементов
- **САМ** — стартерная авиационная моноблочная
- **28** — ёмкость в А·ч при 5-часовом режиме разряда

## Химические процессы

### Разряд
- Положительные пластины: PbO₂ (коричневый)
- Отрицательные пластины: Pb (серый)
- Электролит: раствор H₂SO₄

### Заряд
- Образуется вода и сульфат свинца

### Сульфатация
При глубоком разряде или долгом хранении разряженной — образование крупных кристаллов сульфата свинца, приводящее к выходу батареи из строя.

## Зависимость от температуры

Ёмкость батареи уменьшается с понижением температуры:
- При +25°C — 100% ёмкости
- При +5°C — ~50% ёмкости (примерно в 2 раза меньше возможных запусков ВСУ)

## Режимы эксплуатации

### Нормальный полёт
- Главный переключатель: «Борт»
- Аварийный переключатель: «Автоматическое»
- Батареи подключены к основной и аварийной шинам
- При работающем генераторе — подзарядка

### Аварийный режим (отказ генераторов)
- Автоматическое подключение к аварийной шине
- Время питания: 15-25 мин (день), 11-15 мин (ночь)
- Аварийный переключатель: «Ручное»

### Запуск ВСУ от батарей
- Используется только при отсутствии аэродромного источника
- Не разряжать большими токами

## Подключение к бортовой сети

### Переключатели (электрощиток энергетики)

**Главный переключатель 729** — три положения:
- «Борт» — подключение батарей к сети
- «Выключено» — батареи отключены
- «Аэродром» — подключение аэродромного питания

**Аварийный переключатель 941** — три положения:
- «Ручное» — батареи только к аварийной шине
- «Основная шина» — батареи к обеим шинам
- «Автоматическое» — автоподключение при отказе генераторов

### Шины
- **Основная шина** — все потребители
- **Аварийная шина** — жизненно важные потребители (автоматы с красными точками)

### Контакторы
- 717, 718 — подключение батарей к сети
- 1791 — соединение с основной/аварийной шиной
- 1545 — отсоединение аварийной шины

## Проверка работоспособности

1. Все потребители отключить, выключатели батарей на РК включены
2. Главный переключатель: «Борт», аварийный: «Основная шина»
3. Включить потребитель на 12А (например, ЭЦН-14)
4. Поочерёдно отключать батареи, проверяя напряжение (≥24В)

## Контроль в полёте

- Амперметр «Аккумулятор» — ток нагрузки/подзарядки
- Вольтметр — напряжение каждой батареи (должно быть ~28.5В при зарядке)
- При зашкаливании амперметра влево (>100А) — неисправность батареи

## Для симулятора

Модель аккумулятора должна учитывать:
1. Напряжение разомкнутой цепи (ЭДС) ~25.2В (12 × 2.1В)
2. Внутреннее сопротивление (растёт при разряде)
3. Зависимость ёмкости от температуры
4. Ток подзарядки от генераторов (float charging до 28.5В)
5. Состояние шин (основная/аварийная)
6. Режим разряда: ограничение по напряжению (≥21В)
