# АПД-27 — Панель автоматическая запуска

## Назначение

АПД-27 — панель автоматического запуска двигателей, содержащая **программный механизм** электромоторного типа.

## Программный механизм

### Состав
- Электродвигатель с постоянной частотой вращения якоря
- Набор профилированных дисков (кулачковых шайб)
- Концевые выключатели

### Принцип работы
Электродвигатель вращает диски, которые в соответствии с их профилем в течение определённых интервалов времени нажимают штоки концевых выключателей. При нажатии штока концевой выключатель замыкает цепь питания электромагнитного реле, осуществляющего необходимые включения или выключения.

### Выходы
- Управление контакторами включения стартера
- Управление регулятором РУТ-600Д2
- Управление коробкой ПРК-8А
- Управление катушками зажигания
- Управление электромагнитными клапанами топлива
- Управление аэродромными источниками

## Отключение стартера

Во время запуска двигателя стартер СТГ-18ТМО выключается автоматически:
1. При достижении ротором двигателя **33-48% оборотов** (по сигналу ВС-1А)
2. По истечении **70 секунд** (если обороты не достигнуты)

При холодной прокрутке стартер выключается автоматически только по истечении установленного времени.

## Управление

### Органы на щитке запуска (левый пульт кабины)
- **Переключатель «Левый — Правый»** — выбор двигателя
- **Переключатель «Холодная прокрутка — Запуск»** — выбор программы
- **Кнопка «Запуск»** — включение системы (1-1.5 сек)
- **Кнопка «Прекращение запуска»** — аварийная остановка
- **Лампочка «Работа АПД»** — сигнализация работы программного механизма

### Переключатель «Земля — Воздух»
- В положении «Воздух» напряжение к автоматике не подводится
- Система не может быть включена в полёте

## Сигнализация
- Амперметр «Ток запуска» — ток в якорной обмотке стартера
- Вольтметр «Напряжение запуска» — 0-75В
