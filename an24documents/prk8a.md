# ПРК-8А — Пускорегулирующая коробка

## Назначение

ПРК-8А включается в систему только при запуске двигателя от бортовых источников электроэнергии (генератор ГС-24А и бортовые аккумуляторы).

## Функции

- Обеспечивает заданную последовательность увеличения напряжения генератора ГС-24А
- Необходимо для увеличения частоты вращения вала стартера СТГ-18ТМО
- Содержит регулятор напряжения **РН-180Д2**

## Последовательность напряжения

| Время, сек | Напряжение на якоре, В |
|------------|----------------------|
| 0-3 | 3-7 |
| 3-9 | 20-26 |
| 9-15 | 29-36 |
| 15-20 | 39-47 |
| 20-28 | 43-51 |
| >28 | 51-60 |
