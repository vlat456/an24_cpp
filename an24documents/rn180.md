# РН-180 — Регулятор напряжения

## Назначение

РН-180 — регулятор напряжения, обеспечивающий поддержание выходного напряжения генератора ГС-24А на уровне 28.5В.

## Применение

- **Генераторный режим ГС-24А** (питание бортсети)
- **ПРК-8А** — содержит модификацию РН-180Д2 для режима запуска двигателя

## Принцип работы

РН-180 регулирует **ток возбуждения** генератора:
- При снижении оборотов → увеличивает поле → E растёт → U стабильно
- При повышении оборотов → уменьшает поле → E падает → U стабильно

Для шунтового генератора с самовозбуждением: U ≈ E - I·Ra, где E = c·n·Φ
