# РУТ-600Д2 — Угольный регулятор тока

## Назначение

РУТ-600Д2 — угольный регулятор тока, предназначенный для:
- Ограничения тока в обмотке возбуждения стартера СТГ-18ТМО
- Поддержания заданного уровня тока якоря
- Регулирования вращающего момента стартера

## Принцип работы

Угольный столб представляет собой электрическое сопротивление. При его включении в цепь обмотки возбуждения:
- Уменьшается ток возбуждения
- Уменьшается магнитный поток Фв
- При том же напряжении на якоре — **обороты растут**

Формула оборотов стартера:
```
n = (U - Iя·(Rя + Rд)) / (c · Фв)
```

При уменьшении Фв (ослаблении поля) — знаменатель уменьшается — n увеличивается.

## Применение в цикле запуска

- **9 сек** — включается, ток возбуждения ↓ → обороты ↑
- **15 сек** — выключается (при увеличении напряжения питания)
- **20 сек** — включается повторно
