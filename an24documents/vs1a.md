# ВС-1А — Пневмоэлектрический выключатель

## Назначение

ВС-1А — пневмоэлектрическое реле, предназначенное для автоматического выключения стартера СТГ-18ТМО при достижении ротором двигателя заданной скорости вращения.

## Принцип работы

- Срабатывает за счёт давления воздуха, поступающего из компрессора двигателя
- При достижении оборотов 33-48% давление воздуха становится достаточным для срабатывания

## Функция в системе запуска

При размыкании контактов ВС-1А:
1. Обесточиваются реле и контакторы
2. Отключается электропитание стартера СТГ-18ТМО
3. Аэродромные источники отключаются от шины запуска
4. Программный механизм АПД-27 переключается на ускоренную доработку программы

## Альтернативная отсечка

Если по какой-либо причине частота вращения вала двигателя не достигнет 33-48% до 70-й секунды — стартер выключается автоматически по истечении этого времени.
