# Система запуска ТГ-16М

## Принцип запуска

ТГ-16М запускается **электрическим стартером** постоянного тока, встроенным в корпус газотурбины.

## Последовательность запуска

1. **Источник питания** — аэродромный источник (АР-2) или бортовая аккумуляторная батарея (28В)
2. **Стартер** раскручивает ротор ВСУ до ~750 об/мин
3. **Пневмоэлектрический выключатель ВС-1А** фиксирует достижение оборотов
4. **Отключение стартера** — по сигналу от ВС-1А или по тахометру
5. **Подача топлива** — электромагнитный клапан
6. **Зажигание** — катушка зажигания
7. **Воспламенение** — топливо воспламеняется в камере сгорания
8. **Набор оборотов** — двигатель выходит на режим холостого хода

## Параметры запуска

| Параметр | Значение |
|----------|----------|
| Макс. время холодной прокрутки | 120 сек |
| Обороты стартера | ~750 об/мин |
| Расход масла | 5-27 л (допустимо 3.5 л кратковременно) |
| Давление масла | 0.30-0.45 МПа (3.0-4.5 кг/см²) |

## Контроль запуска

- Обороты турбины (91-94% — готов к запуску)
- Температура масла (допустимый диапазон)
- Давление масла (0.30-0.45 МПа)
- Расход масла

## Отсечка стартера

Стартер автоматически отключается:
1. При достижении оборотов пневмоэлектрическим выключателем
2. По истечении максимального времени прокрутки (120 сек)

## Для симулятора

Модель запуска ВСУ должна включать:
1. Потребление тока стартером (пусковой ток ~100-200А)
2. Нарастание оборотов (dt от 0 до 750 об/мин)
3. Отсечка стартера при достижении оборотов
4. Задержка на воспламенение (~1-2 сек после подачи топлива)
5. Набор оборотов холостого хода после запуска
