# Распределение электроэнергии постоянного тока Ан-24

## Источники электроэнергии

### Бортовые источники
| Источник | Напряжение | Мощность |
|----------|------------|-----------|
| Генератор СТГ-18ТМО (×2) | 28.5В | 18 кВт (600А) |
| Генератор ГС-24А (ВСУ) | 28.5В | — |
| Аккумулятор 12-САМ-28 (×2) | 24В | 28А·ч |

### Аэродромные источники
| Источник | Напряжение |
|----------|------------|
| АПР-2 (аэродромный источник) | 28.5В |
| АР-1, АР-2 | 28.5В (каждый) |

## Шины постоянного тока

### Основные шины

На самолёте имеются **основные шины** и **аварийная шина**.

#### Основная шина
- Питается от генераторов СТГ-18ТМО, ГС-24А или аэродромных источников
- Все потребители электроэнергии

#### Аварийная шина
- Жизненно важные потребители
- Автоматы защиты помечены **красными точками**
- При отказе генераторов — автоматическое подключение аккумуляторов

### Центральные распределительные устройства (ЦРУ)

На самолёте два **центральных распределительных устройства**:

| ЦРУ | Расположение | Привязка |
|-----|--------------|-----------|
| **Левое ЦРУ** | Левый борт | Подключено к СТГ левого двигателя |
| **Правое ЦРУ** | Правый борт | Подключено к СТГ правого двигателя |

#### В каждом ЦРУ размещены:
- Дифференциально-минимальное реле **ДМР-600Т**
- Регулятор напряжения **РН-180**
- Автоматы защиты от перенапряжения **АЗП-8М**

#### Шины ЦРУ
- От шины **левого ЦРУ** питается большинство основных потребителей:
  - Система флюгирования винтов
  - Электродвигатели подкачивающих насосов топливной системы
  - Другие потребители левого борта
- От шины **правого ЦРУ** — потребители правого борта

#### Особенности
- Основные шины левого и правого ЦРУ соединены между собой
- При работе обоих генераторов — параллельная работа через уравнивание напряжений
- Нормальное положение вольтметра — «ЦРУ лев.» (приоритет контроля)

### Шина запуска
- Отдельная шина для питания стартера СТГ-18ТМО
- Подключается от аэродромных источников или ГС-24А

## Система подключения источников

### Принцип работы

```
                    │           Основная шина                  │
                    │  (все потребители)                      │
                    └──────────┬───────────────┬───────────────┘
                               │               │
              ┌───────────────┴───┐   ┌───────┴───────────────┐
              │    Левое ЦРУ      │   │     Правое ЦРУ       │
              │  ДМР-600Т        │   │     ДМР-600Т         │
              │  РН-180           │   │     РН-180            │
              │  АЗП-8М           │   │     АЗП-8М            │
              └─────────┬─────────┘   └──────────┬──────────┘
                        │                          │
                        │    Шины соединены        │

              │                                                     │

    │    СТГ-18ТМО      │     │     ГС-24А          │     │   АПР-2   │
    │    (левый)        │     │   (от ВСУ ТГ-16)    │     │(аэродром)│
    └───────────────────┘     └──────────────────────┘     └───────────┘

                    ┌─────────────────────────────────────────┐
                    │           Аварийная шина                │

                    │      12-САМ-28             │
                    └────────────────────────────┘
```

### Блокировка источников

Электрическая блокировка не позволяет подключить генератор СТГ-18ТМО, если к сети подключён аэродромный источник.

### Переключатели

**Главный переключатель 729** (три положения):
- «Борт» — батареи к сети
- «Выключено» — отключено
- «Аэродром» — аэродромное питание

**Аварийный переключатель 941** (три положения):
- «Ручное» — батареи только к аварийной шине
- «Основная шина» — батареи к обеим шинам
- «Автоматическое» — автоподключение при отказе генераторов

## Режимы работы

### Нормальный полёт
- Главный: «Борт»
- Аварийный: «Автоматическое»
- Генераторы СТГ-18ТМО подключены
- Аккумуляторы на подзарядке

### Отказ генераторов
- Автоматическое отключение основной шины
- Аккумуляторы подключаются к аварийной шине
- Время питания: 15-25 мин (день), 11-15 мин (ночь)

### Запуск от ВСУ
- Бортовая сеть питается от аккумуляторов
- После запуска первого двигателя — подключить его генератор
- Затем запуск второго двигателя

## Контроль

### Приборы на электрощитке энергетики
- **Вольтметр** (0-30В × 10) — общее напряжение сети
- **Амперметры СТГ** (–100…1000А) — ток каждого генератора
- **Амперметр «Аккумулятор»** — ток заряда/разряда
- **Лампы «Отказ СТГ»** (×2) — красные, горят при отключении генератора

### Переключатель вольтметра
Позitions:
- «ЦРУ лев.» (нормальное положение)
- «ЦРУ прав.»
- «Генератор СТГ лев.»
- «Генератор СТГ прав.»
- «Генератор ГС-24А»
- «Аварийная шина»
- «Аккумулятор 1»
- «Аккумулятор 2»

## Автоматы защиты (АЗС)

Расположение на щите АЗС:
- Потребители основной шины
- Потребители аварийной шины (помечены красными точками)
- Автомат АЗР-6 «Останов двигателей» — стоп-краны

## Для симулятора

### Модель распределения

```
Sources: [СТГ-1, СТГ-2, ГС-24А, АПР-2, Аккум-1, Аккум-2]
Buses:   [ЦРУ-Левое, ЦРУ-Правое, ШинаАварийная, ШинаЗапуска]

Rules:
- ШинаЗапуска подключается к АПР-2 или ГС-24А
- ЦРУ-Левое подключается к СТГ-1 или АПР-2
- ЦРУ-Правое подключается к СТГ-2 или АПР-2
- ЦРУ-Левое и ЦРУ-Правое соединены между собой (параллельная работа)
- ШинаАварийная подключается к ЦРУ-Левое/ЦРУ-Правое (норм) или Аккум-1, Аккум-2 (авария)
- Блокировка: нельзя подключить СТГ при подключённом АПР-2
```

### Распределение потребителей по бортам

| Потребители левого ЦРУ | Потребители правого ЦРУ |
|------------------------|-------------------------|
| Система флюгирования винтов | Радиооборудование |
| Топливные подкачивающие насосы | Навигационное оборудование |
| Приборы левого пилота | Приборы правого пилота |
| ... | ... |

### Уравнивание нагрузки генераторов

При параллельной работе генераторов:
- Допустимая разность токов: ≤60А
- Регулировка: выносными сопротивлениями ВС-25Б
- Если нет балластных сопротивлений БС-1800 — роль выполняют провода обмоток

### Параметры для моделирования

| Параметр | Значение |
|----------|----------|
| Номинальное напряжение | 28.5В |
| Диапазон работы | 27-28.5В |
| Порог отключения по перенапряжению | >32В |
| Порог подключения генератора | >24.2В (на 0.2-1В выше сети) |
| Обратный ток отключения | 25-50А |
